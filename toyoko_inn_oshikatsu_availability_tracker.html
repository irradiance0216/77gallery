How to Build an Automated Toyoko Inn Scraper

Toyoko Inn's standard room cancellation policy allows guest cancellations with no fee up until 16:00 on the day of check-in (or 1-3 days prior depending on group/event rules). Oshikatsu fans often hoard multiple hotel options across different areas until event seating or schedules are finalized, resulting in a **massive surge of cancellation drops 24 to 48 hours prior**.

1

1. Web Crawling / API Scraper

Uses Python (Playwright / BeautifulSoup) or Node.js to send query requests to Toyoko Inn's official availability search form with specific hotel codes & dates.

2

2. Scheduled Cron & State Check

Runs every 1-3 minutes via GitHub Actions, AWS Lambda, or a local server. Compares current room status (e.g., changing from 滿室 to 殘室少 or 空室) against previous database state.

3

3. Instant Alert Trigger

Upon detecting an open room, dispatches instant Web Push, LINE Notify API, or Telegram Bot notifications with a direct pre-filled booking URL for immediate reservation.

import asyncio
import requests
from playwright.async_api import async_playwright

# Toyoko Inn Scraping Script for Oshikatsu Room Drops
LINE_NOTIFY_TOKEN = "YOUR_LINE_NOTIFY_TOKEN"
TARGET_HOTEL_URL = "https://www.toyoko-inn.com/china/search/reserve/room" # Toyoko Inn Official endpoint

async def check_toyoko_availability(hotel_code, checkin_date):
    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        page = await browser.new_page()
        
        # Navigate to target Toyoko Inn branch search page
        url = f"https://www.toyoko-inn.com/search/result?chl={hotel_code}&ch_in={checkin_date}"
        print(f"[*] Checking availability for Hotel Code {hotel_code} on {checkin_date}...")
        
        await page.goto(url, wait_until="networkidle")
        
        # Parse availability elements (e.g. looking for '空室あり' or room count badges)
        room_cards = await page.query_selector_all(".room-type-card")
        
        available_rooms = []
        for card in room_cards:
            title = await card.query_selector(".room-name")
            status = await card.query_selector(".status-badge")
            
            title_text = await title.inner_text() if title else "Unknown Room"
            status_text = await status.inner_text() if status else "Full"
            
            if "空室" in status_text or "残り" in status_text:
                available_rooms.append((title_text, status_text))
                
        await browser.close()
        
        if available_rooms:
            message = f"\n🚨 TOYOKO INN ROOM OPENING!\nHotel: {hotel_code}\nDate: {checkin_date}\nRooms: {available_rooms}\nBook NOW: {url}"
            send_line_notify(message)
            print("[+] ALERT SENT: Room Available!")
        else:
            print("[-] Still full (滿室). Checking again on next cron tick.")

def send_line_notify(message):
    headers = {"Authorization": f"Bearer {LINE_NOTIFY_TOKEN}"}
    data = {"message": message}
    requests.post("https://notify-api.line.me/api/notify", headers=headers, data=data)

const puppeteer = require('puppeteer');
const axios = require('axios');

const TELEGRAM_BOT_TOKEN = 'YOUR_TELEGRAM_BOT_TOKEN';
const TELEGRAM_CHAT_ID = 'YOUR_CHAT_ID';

async function monitorToyokoInn(hotelId, checkInDate) {
    console.log(`[${new Date().toISOString()}] Scanning Toyoko Inn (${hotelId}) for ${checkInDate}...`);
    const browser = await puppeteer.launch({ headless: true });
    const page = await browser.newPage();
    
    // Set headers to prevent scraping block
    await page.setUserAgent('Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36');
    
    const searchUrl = `https://www.toyoko-inn.com/search/result?chl=${hotelId}&checkin=${checkInDate}`;
    await page.goto(searchUrl, { waitUntil: 'domcontentloaded' });

    // Check for availability DOM elements
    const isAvailable = await page.evaluate(() => {
        const bodyText = document.body.innerText;
        return bodyText.includes('空室あり') || bodyText.includes('残りわずか');
    });

    if (isAvailable) {
        const msg = `🚨 TOYOKO INN CANCELLATION DROP!\nHotel: ${hotelId}\nDate: ${checkInDate}\n\nQuick Link: ${searchUrl}`;
        await axios.post(`https://api.telegram.org/bot${TELEGRAM_BOT_TOKEN}/sendMessage`, {
            chat_id: TELEGRAM_CHAT_ID,
            text: msg
        });
        console.log("ALERT SENT TO TELEGRAM!");
    } else {
        console.log("No rooms currently available.");
    }

    await browser.close();
}

// Execute every 60 seconds
setInterval(() => monitorToyokoInn("00088", "2026-10-15"), 60000);
